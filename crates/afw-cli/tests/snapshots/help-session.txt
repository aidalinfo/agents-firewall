Editing sessions: open, show, discard, publish

Usage: afw session [OPTIONS] <COMMAND>

Commands:
  open     Open an editing session
  show     Show a session (default: yours) with its locks and pending changes
  list     List open sessions
  discard  Discard a session (default: yours) and release its locks
  publish  Publish a session (default: yours) as a new revision
  help     Print this message or the help of the given subcommand(s)

Options:
      --json            Print JSON instead of tables
      --config <FILE>   Configuration file [default: ~/.config/afw/config.toml] [env: AFW_CONFIG=]
      --url <URL>       Console URL (overrides the configuration) [env: AFW_URL=]
      --ca-cert <FILE>  Extra trusted CA certificate, PEM (overrides the configuration) [env: AFW_CA_CERT=]
      --session <ID>    Editing session to use (default: your open session) [env: AFW_SESSION=]
  -h, --help            Print help
  -V, --version         Print version
