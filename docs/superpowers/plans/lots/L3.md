# L3 — Console (maquette, données mock) — plan de lot

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal :** console web Nuxt 4 + Nuxt UI 4 fidèle à `docs/design/maquette/project/*.dc.html`, branchée sur une
interface `AfwApi` avec une implémentation mock riche (données de la maquette) et une implémentation HTTP
(fetch + SSE) sélectionnées par `NUXT_PUBLIC_API_MODE=mock|http`.

**Architecture :** SPA Nuxt (`ssr: false`, servie par Nitro node-server). Aucune logique métier côté client :
la trace d'évaluation, les compteurs, les propositions « Autoriser » et les vérifications viennent de l'API
(simulées par `mock.ts`). Tokens de couleur de la maquette en variables CSS (`:root` clair, `.dark` sombre par
défaut), mappés sur les variables Nuxt UI (`--ui-*`) et exposés à Tailwind 4 via `@theme inline`.

**Tech Stack :** Nuxt 4, Nuxt UI 4 (Tailwind 4, @nuxt/icon + lucide local, @nuxt/fonts Geist/Geist Mono),
@nuxtjs/i18n 10 (fr par défaut, en), Vitest 3 + @nuxt/test-utils + happy-dom, ESLint (@nuxt/eslint), vue-tsc.
