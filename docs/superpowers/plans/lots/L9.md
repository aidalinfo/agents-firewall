# L9 — Serveur MCP `afw-mcp` : plan détaillé

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Étapes en cases à cocher.

**Goal :** binaire `afw-mcp` (rmcp 0.8, transports stdio et HTTP streamable) exposant à l'agent agréé les mêmes
opérations que la CLI, via `afw-client` avec `Interface::Mcp` et un jeton `mcp_agent` (EF-40, EF-46, EF-51, EF-52).

**Principes :** aucun contrôle d'autorisation côté MCP (l'API est l'autorité) ; les refus sont rendus lisibles :
403 → résultat d'outil en erreur expliquant la délégation ; publication 202 → résultat expliquant l'approbation
humaine en attente. Les descriptions d'outils rappellent que l'agent ne peut pas modifier sa propre zone. ADR : 0025.
