# Lot L6 — `afw-gateway` : plan détaillé

> Plan d'exécution du lot L6 (plan maître §4, « L6 — afw-gateway »). TDD, tests de contournement d'abord.

**But :** le plan de données : une passerelle par hôte d'agents qui intercepte tout (écoute transparente
`SO_ORIGINAL_DST`, proxy explicite, DNS), décide avec la politique compilée, inspecte TLS, analyse les contenus
(DLP), coupe dès détection, journalise tout et ne tombe jamais en mode ouvert.

**Dépendances :** `afw-core` (contrats), `afw-tls` (CA d'inspection, client amont, identité mTLS). `afw-engine`
(L5) et `afw-dlp` (L1) arrivent en parallèle : la passerelle code contre leurs API figées derrière deux modules
d'adaptation (`engine`, `dlp`) ; tant qu'ils ne sont pas fusionnés, des cales minimales (`engine_shim`,
`dlp::shim`) servent aux tests, remplacées au rebase sans toucher au reste du code.

**Décisions :** ADR 0017 (architecture du plan de données et pipeline), ADR 0018 (nom contrôlé par la politique,
DNS filtrant et attribution par cache DNS), ADR 0019 (inspection des contenus : tampon, flux, WebSocket,
décompression).

## Fichiers (`crates/afw-gateway`)
- `src/lib.rs` (assemblage `Gateway`, état partagé), `src/main.rs` (binaire : `run`, `register`).
- `src/config.rs` : clap + variables d'environnement (`AFW_CONSOLE_URL`, `AFW_CONSOLE_CA_FILE`,
  `AFW_REGISTRATION_TOKEN`, `AFW_GATEWAY_NAME`, `AFW_STATE_DIR`, `AFW_CA_EXPORT`, `AFW_INTERNAL_IFACE`,
  `AFW_INTERNAL_SUBNETS`, `AFW_UPSTREAM_DNS`, `AFW_UPSTREAM_CA_FILE`/`AFW_EXTRA_CA`, `AFW_INTERCEPT`,
  ports, `--standalone-policy`).
- `src/engine.rs`, `src/engine_shim.rs` : contrat du moteur (L5) et cale.
- `src/dlp.rs` : contrat d'analyse (`ContentScanner`, flux à recouvrement avec `safe_len`), cale.
- `src/policy_store.rs` : chargement/persistance atomique, vérification, dernière valide, tout refuser sinon.
- `src/transparent.rs`, `src/explicit_proxy.rs`, `src/flow.rs` (classification + aiguillage commun),
  `src/sniff.rs` (ClientHello/SNI, requête HTTP/Host), `src/tls_mitm.rs`, `src/http_pipeline.rs`,
  `src/admin.rs` (actions d'administration), `src/websocket.rs`, `src/dns.rs`, `src/l4.rs`, `src/upstream.rs`
  (résolution, métadonnées cloud), `src/events.rs`, `src/alerts.rs`, `src/capture.rs`, `src/health.rs`,
  `src/metrics.rs`, `src/console_client.rs`, `src/io.rs` (flux préfixé, comptage, coupure RST).
- `tests/bypass.rs` (contournements), `tests/common/mod.rs` (passerelle en processus, amonts TLS locaux).
- `deploy/docker/Dockerfile.gateway`, `deploy/docker/gateway-entrypoint.sh`,
  `deploy/docker/isolation-test/` (compose + `run.sh`, test réseau réel ENF-07).
