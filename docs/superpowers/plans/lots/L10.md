# Lot L10 — `afw-import` : import de la politique egress-guard (plan détaillé)

> Sous-plan du plan maître (`../2026-10-30-agents-firewall-v1.md`, §4 L10). ADR du lot : 0026.
> Exigences : EF-70, EF-71, EF-72 ; conception §2, §5.4, §11, §15 ; ADR 0005, 0012, 0015, 0016.

**But :** convertir un fichier egress-guard « v2 egress-first » (`pulse-mcp-guardrails.yaml`) en un plan
d'import applicable dans une session de l'API : objets, services, classes de données, zone (en observation par
défaut), règles (socle + zone), politique d'intention du plugin Hermes, et un rapport d'import lisible.
La CLI (lot L8) applique le plan ; la crate ne dépend pas d'`afw-client`.

- `crates/afw-import/src/egress_guard/format.rs` — format YAML reconstruit (structures serde, champs inconnus
  recueillis par `#[serde(flatten)]` pour être signalés).
- `crates/afw-import/src/egress_guard/mod.rs` — `ImportOptions`, `import`, conversion.
- `crates/afw-import/src/plan.rs` — `ImportPlan`, `SessionChange`, `to_session_changes`, `merged_into`.

- `docs/adr/0026-import-egress-guard.md` ; mise à jour de `docs/migration-egress-guard.md`.
