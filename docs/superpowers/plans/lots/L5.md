# Lot L5 — `afw-engine` : plan détaillé

> Sous-plan du plan maître (`../2026-10-30-agents-firewall-v1.md`, §3.1 et §4 L5). ADR du lot : 0016.

**But :** compiler une `InstalledPolicy` en une structure d'évaluation rapide, décider chaque flux selon l'ordre
figé (socle → zone → interne surveillé → nettoyage), appliquer observation, exemption LLM et inspection TLS, et
fournir la vérification avant installation (EF-11) et « où est-ce utilisé » (EF-02).

## Fichiers
- `crates/afw-engine/src/lib.rs` — types publics : `FlowContext`, `Decision`, `DecisionLayer`, `Implicit`,
  `TraceStep`, `TraceOutcome`, méthodes `Decision::to_ref`, `Decision::deny_message`.
- `crates/afw-engine/src/matching.rs` — normalisation des noms (casse, point final, ASCII seulement),
  jokers, normalisation des chemins (décodage percent, `.`/`..`, `//`, `\`), ensembles de destinations compilés.
- `crates/afw-engine/src/compile.rs` — `CompiledPolicy`, `CompileError`, `compile`, `deny_all`, `evaluate`,
  `resolve_agent`, `revision`, `is_llm_provider`, `data_class_specs`.
- `crates/afw-engine/src/verify.rs` — `verify`, `verify_warnings`, `where_used`, `Usage`.
- `crates/afw-engine/tests/bypass.rs` — tests de contournement (écrits d'abord).
- `crates/afw-engine/tests/engine.rs` — tests de comportement, vérification, bench `#[ignore]`.
- `docs/adr/0016-moteur-de-regles.md` — choix non triviaux.
