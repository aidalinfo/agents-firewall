# L11 — `afw-enroll` : plan détaillé

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Étapes en cases à cocher.

**Goal :** bibliothèque Rust autonome (sans `afw-core`) qui enrôle un agent conteneurisé derrière la passerelle :
transformation Docker Compose et son inverse exacte, client Coolify v4, manifestes Kubernetes, arguments `docker run`.

**Exigences :** EF-60, EF-61 (montage du plugin Hermes), EF-63, EF-64, ADR 0003 (motif « pause »), ADR 0023.

**Architecture :** `serde_yaml::Value` (l'ordre des clés est conservé par `Mapping`) ; un module par cible :
`compose.rs` (enroll/unenroll), `coolify.rs` (client reqwest + `enroll_coolify`), `k8s.rs` (manifestes + patch de
gabarit de pod), `docker.rs` (`docker run`), `spec.rs` (types communs), `error.rs`.

## Tâches

- [ ] 1. Squelette de crate (`Cargo.toml` en `workspace = true`, `lib.rs`, `error.rs`, `spec.rs`).
- [ ] 2. Tests de contournement d'abord (`tests/compose.rs`) : `network_mode: host` → erreur ; agent `privileged`,
      `cap_add: NET_ADMIN/SYS_ADMIN/ALL`, socket Docker monté (forme courte et longue), `pid: host` → avertissements ;
      `network_mode: service:x`/`container:x` existant → erreur ; deuxième enrôlement → `AlreadyEnrolled` ;
      l'agent enrôlé n'a plus ni `networks`, ni `ports`, ni `dns`, ni `cap_add NET_ADMIN` ajouté ; le conteneur
      `afw-net-<agent>` seul porte `NET_ADMIN`, l'IP fixe et le DNS de la passerelle.
- [ ] 3. `enroll_compose` : service `afw-net-<agent>` inséré juste avant l'agent, déplacement des options
      incompatibles avec `network_mode: service:` (ports, expose, dns*, extra_hosts, hostname, domainname,
      mac_address ; `networks`/`links` retirés), variables de proxy (majuscules + minuscules) et de CA, montage CA,
      Hermes (plugin + `AFW_CONSOLE_URL`, `AFW_AGENT_TOKEN=${<var>}`, `AFW_AGENT_NAME`), réseau `external: true`,
      annotation `x-afw-original`. Snapshot YAML (`tests/fixtures/*.expected.yml`).
- [ ] 4. `unenroll_compose` : inverse exacte (égalité sémantique avec l'original, y compris un réseau déjà déclaré
      et un compose sans `networks`), erreur `NotEnrolled`.
- [ ] 5. `docker_run_args` / `netinit_run_args` (EF-63).
- [ ] 6. Coolify : `CoolifyClient` (GET/PATCH `applications|services/{uuid}`, `docker_compose_raw` en base64 à
      l'écriture, `POST …/restart`), `enroll_coolify` / `unenroll_coolify`. Tests avec un faux serveur axum
      (vérifie l'en-tête `Authorization`, le base64, l'ordre lecture → mise à jour → redémarrage, erreurs HTTP).
- [ ] 7. Kubernetes : `k8s_manifests` (Secret, ConfigMap CA, PVC d'état, Deployment, Service ClusterIP fixe,
      NetworkPolicy) ; `patch_pod_template` (Deployment/StatefulSet/DaemonSet/Job/Pod). Tests : structure,
      NetworkPolicy sans `ipBlock` ni `to` vide, ports limités, `hostNetwork` refusé, idempotence.
- [ ] 8. ADR 0023 ; `fmt`, `clippy -D warnings`, tests ; PR.
