# Lot L1 — `afw-dlp` : plan détaillé

> Plan d'exécution du lot L1 (plan maître §4). Crate autonome : aucune dépendance vers `afw-core` ;
> l'orchestrateur convertit `afw_dlp::Finding` vers le type partagé.

**Objectif :** classes de données, détecteurs intégrés et personnalisés, analyse d'un tampon, d'en-têtes,
d'URL et d'un flux continu (fenêtre glissante), masquage `[CATEGORIE:kind:empreinte]`.

**Architecture :** détecteurs = expressions régulières `regex::bytes` (aucune hypothèse UTF-8) + validateurs
(Luhn, mod 97, entropie de Shannon, octets d'IP). Chaque tampon est analysé tel quel puis dans des variantes
décodées (percent-encoding, échappements JSON, segments base64 plausibles), récursivement sur deux niveaux ;
toute détection dans une variante est rapportée sur la plage correspondante de l'original. Le flux garde
`max_pattern_len` octets de recouvrement, diffère toute détection qui touche la fin du tampon et
dédoublonne par position absolue.

**Pile :** Rust 2024, `regex`, `sha2`, `hex`, `base64`, `serde`, `thiserror`. ADR : `docs/adr/0012-detection-dlp.md`.

## Tâches

1. **Squelette de crate** — `crates/afw-dlp/Cargo.toml`, `src/lib.rs` avec l'API publique exacte
   (types, `Scanner`, `StreamScanner`, `mask`, `mask_bytes`, `builtin_classes`) et des corps vides,
   pour que les tests compilent et échouent.
2. **Tests de contournement d'abord** (`tests/bypass.rs`) : secret coupé entre deux `feed` (dont au milieu
   de `sk-ant-`), base64, percent-encoding, JSON échappé (`\"`), multipart (champ et partie base64 repliée),
   en-tête, requête d'URL, mots-clés en majuscules ; même secret → même empreinte ; masquage sans fragment ;
   octets non UTF-8 aléatoires (PRNG xorshift déterministe) sans panique ; faux positifs : UUID, SHA-1 git,
   URL S3 présignée (EF-72). Commit « test » avec tests rouges.
3. **Tests par détecteur** (`tests/detectors.rs`) : un cas positif et un cas négatif par identifiant, classes
   par défaut, sérialisation serde (`snake_case`, `type`), erreurs (`UnknownDetector`, `InvalidPattern`).
4. **Implémentation** : `detectors.rs` (motifs + validateurs), `decode.rs` (variantes + table de
   correspondance des positions), `scanner.rs` (analyse, en-têtes, URL, exclusion des paramètres
   `X-Amz-*` d'une URL présignée), `stream.rs`, `mask.rs`. Tests verts.
5. **Banc de débit** : test `#[ignore]` sur 10 Mo, chiffre noté dans le rapport et l'ADR.
6. **ADR 0012**, `fmt`, `clippy -D warnings`, `test`, push, PR vers `dev`.
